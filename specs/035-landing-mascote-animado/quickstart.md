# Verificação rápida

1. Execute `npm run dev` e abra `/`.
2. Confira Hifro no herói, sem controles ou som; observe dois ciclos.
3. Ative movimento reduzido no sistema ou no DevTools: Hifro deve ficar estático.
4. Use largura de 375 px e 1440 px: não deve haver sobreposição nem rolagem horizontal causada pelo herói.
5. Em rede, verifique que a página solicita `/media/hifro-mascote-hero.webm` quando o herói fica visível e que o arquivo original de Downloads não é servido.
